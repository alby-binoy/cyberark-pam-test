# What is Privileged Access Management (PAM)?

## Overview

Privileged Access Management (PAM) is a security practice used to protect, control, and monitor access to accounts that have elevated or privileged permissions.

Examples of privileged accounts include:

- Administrator accounts
- Root accounts
- Domain administrator accounts
- Database administrator accounts
- Service accounts with elevated permissions
- Application accounts with privileged access

The purpose of PAM is to ensure that privileged access is provided only when required and that the access can be controlled, monitored, and audited.

## Why is PAM Important?

Privileged accounts can perform sensitive operations such as:

- Installing or removing software
- Changing system configurations
- Creating or deleting users
- Accessing sensitive data
- Starting or stopping services
- Modifying security settings

If a privileged credential is compromised, it can potentially be used to gain significant access to an environment.

PAM helps organizations reduce this risk by applying controls around privileged credentials and sessions.

## Common PAM Capabilities

A PAM solution commonly provides capabilities such as:

1. **Credential Management**
   - Secure storage of privileged credentials
   - Password rotation
   - Controlled access to credentials

2. **Access Control**
   - Granting privileged access only to authorized users
   - Applying role-based access controls

3. **Session Management**
   - Controlling privileged sessions
   - Recording or monitoring sessions where required

4. **Auditing**
   - Tracking privileged access
   - Maintaining logs for investigation and compliance

5. **Just-in-Time Access**
   - Providing privileged access only for the required period

## CyberArk and PAM

CyberArk is an identity security platform that provides solutions for protecting privileged and other sensitive identities.

CyberArk PAM can help organizations manage privileged accounts, control access to those accounts, secure credentials, and monitor privileged sessions.

Some commonly encountered CyberArk components include:

- Digital Vault
- PVWA (Password Vault Web Access)
- CPM (Central Policy Manager)
- PSM (Privileged Session Manager)

The exact architecture and components used can vary depending on the organization's implementation.
